# Meridian

A Next.js and Tailwind CSS web app with a marketing landing page and an admin dashboard[cite: 1, 4].

## What's Inside

- **Landing Page (`/`)**: Navigation bar, hero section, product preview, features, how it works, pricing plans, testimonials, FAQ, and footer[cite: 1].
- **Dashboard Overview (`/dashboard`)**: Summary stat cards and revenue/bar charts[cite: 1].
- **User Management (`/dashboard/users`)**: User table with search, filters, and add, edit, and delete actions[cite: 1].
- **Settings (`/dashboard/settings`)**: Workspace and profile settings controls[cite: 1].
